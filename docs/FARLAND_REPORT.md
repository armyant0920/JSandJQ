# 參考評估：神奇傳說 時空道標（Farland Saga 2）

## 基本資料
- 日本 TGL 開發的戰略角色扮演遊戲（SRPG），1997/5 日文版，同年 8 月推出繁體中文版（台灣代理、智冠總經銷）；平台 Windows / Saturn / PlayStation。
- 2025 年有 Steam 版「FARLAND SAGA II Saturn Tribute」，加入快速戰鬥、常駐狀態顯示、回溯（Rewind）與快速存讀。
- 前作為《神奇傳說》（Farland Story，1993 PC-98 起家）。系列以可愛畫風與棋子式回合戰鬥著稱。

## 遊玩特色（多個來源交叉整理）
| 特色 | 內容 |
|---|---|
| 45 度視角 + 高低差 | 地圖有高度，近戰時高處較有利；評論指出遠程與魔法不受高度影響、障礙物也不擋飛行道具 |
| 單位朝向 | 角色有面向，正面/背面受到的傷害不同（系列一代即有） |
| 突進攻擊 | 角色直線衝向敵人時會發動突進，各角色有專屬突進動作 |
| 地形效果 | 地形影響防禦與迴避 |
| 敵方 AI 類型 | 突擊、慎重、伏擊、逃跑 |
| 公會委託制 | 在港都公會接受委託推進劇情，可選接受/拒絕（拒絕只改變對話） |
| 武器決定攻擊動作 | 不同武器有不同攻擊動畫；魔法隨等級變強 |
| 飛行單位 | 可上高台攻擊高處的敵方法師（攻略常見戰術） |

## 是否適合加入本專案
| 元素 | 適合度 | 成本 | 建議做法 |
|---|---|---|---|
| **單位朝向與背擊** | ★★★ | 低（單位已有 dir） | 行動結束時自動面向最後移動方向（或手動選擇）；從側面/背面攻擊命中與傷害加成，劇本可開關 |
| **突進攻擊** | ★★★ | 低（已有移動路徑與「突進」演出模板） | 直線移動 N 格後的近戰攻擊獲得傷害加成並播放突進演出；由武器或技能（`charge`）開啟 |
| **AI 類型：伏擊／逃跑** | ★★★ | 低 | 新增 `ambush`（玩家進入指定範圍或旗標成立才整隊出動）、`flee`（帶寶物往撤退點跑，逃走即失去寶物）；已有突擊=aggressive、慎重=cautious |
| **回溯（悔棋）** | ★★★ | 低～中（戰場狀態本來就可序列化） | 每個我方行動前存快照，選單「回到上一步」，劇本可限制次數或關閉 |
| **高低差** | ★★ | 中 | 不改 45 度視角，在 2D 地圖加「高度層」（地圖編輯器高度筆刷、格子陰影與數字顯示）；近戰從高處 +命中/+傷害；飛行單位無視高度 |
| **公會委託／據點** | ★★ | 中～高 | 章節之間加入「據點畫面」：主線委託 + 可重複的支線委託（練等、賺錢、招募），與現有出擊準備、劇情分歧整合 |
| 45 度等角視角 | ★ | 高（渲染、點選、編輯器全面改寫） | 暫不建議；高低差與朝向用 2D 表現即可得到大部分玩法 |

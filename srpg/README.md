# SRPG 戰棋（網頁版）

火焰之紋章 / 超級機器人大戰類型的回合制戰棋遊戲，附劇本編輯器與 AI 協作繪圖流程。
**純前端、零相依套件**：雙擊 `index.html` 就能玩，存檔在玩家自己的瀏覽器 / 檔案中。

| 檔案 | 說明 |
|---|---|
| `index.html` | 遊戲本體 |
| `editor.html` | 劇本編輯器（地圖、角色、職業、武器、道具、技能、精神指令、支援、地形、精靈圖、對話劇本、AI 協作） |
| `data/demo-campaign.js` | 內建示範劇本「邊境的晨星」：5 章、選項分歧、說服、拜訪、增援、轉職、改造（由 `tools/build_demo.py` 產生） |
| `tools/balance.js` | 數值平衡統計：`node srpg/tools/balance.js 60` 讓 AI 自動打完整套劇本，輸出每章勝率 |
| `js/core/` | 純邏輯（可用 Node 測試）：規則、戰場、AI、劇本直譯器、存檔、出擊準備 |
| `js/render/` | Canvas 繪製：ASCII 精靈、程序化地形、戰鬥演出 |
| `js/audio/` | WebAudio 合成音效/BGM、玩家設定 |
| `js/ui/`、`js/game.js` | 遊戲 UI 與流程 |
| `js/editor/` | 編輯器 |
| `assets/` | 角色行走圖、武器/道具圖示 |
| `tests/` | `node --test srpg/tests/*.test.js` |

設計文件與里程碑：[`docs/SRPG_PLAN.md`](../docs/SRPG_PLAN.md)

## 遊戲操作
- 點我方單位 → 藍色格移動 → 選擇行動：
  - **攻擊**：選目標後顯示戰鬥預測，可用 ◀ ▶（或方向鍵）切換武器。
  - **杖**：治療相鄰受傷同伴（回復 = 魔力 + 杖的回復量）。
  - **精神**：消耗 SP 的 SRW 風格指令（必中、閃避、熱血、鐵壁、加速、集中、努力、信賴、氣合、激勵）；不會結束行動，「加速」後可重新移動。
  - **道具**：傷藥、萬靈藥、能力提升、SP 回復藥（使用後結束行動）。
  - **交換**：與相鄰同伴交換武器/道具（不結束行動）。
  - **地圖兵器**：範圍攻擊（爆炸或直線），選中心點/方向，橘色為影響範圍；不會被反擊。
  - **救出 / 放下**：把相鄰同伴扛起來帶走（搬運中技巧、速度減半），再放到相鄰空格。
  - **支援**：支援值足夠的兩人相鄰時播放支援對話，升級後在 3 格內互相提供命中/迴避/傷害加成。
  - **交談 / 拜訪 / 壓制 / 待機**（資源系統開啟時，待機可喘口氣回復體力）。
  - **再移動**：有此技能的角色（騎士、天馬騎士）行動後可用剩餘移動力再移動，Esc 留在原地。
- 點敵人可看其移動與攻擊範圍；「⚠ 危險範圍」顯示全部敵人範圍。
- 鍵盤：方向鍵移動游標、`Enter`/`Z` 確定、`Esc`/`X`/右鍵 取消、`E` 結束回合、`D` 危險範圍、`M` 選單。
- 規則（GBA 火紋風格）：武器相剋（劍>斧>槍>劍）、速度差 ≥4 追擊、反擊、必殺 3 倍、地形防禦/迴避、特效武器（弓對飛行）、勇者武器連擊、經驗與成長率升級、永久死亡（可在劇本關閉）。
- **體力 / 法力**（劇本可開關）：強力招式消耗體力、魔法與杖消耗法力，反擊也會消耗；每回合自動回復一些。
- **被動技能**：再移動、先制、追擊、連續、太陽、月光、銳眼、堅守等，可在編輯器自訂，劇情中可「學會」。
- **敵方 AI**：主動進攻、範圍內才行動、原地不動、慎重（不打會被反擊打倒的仗）。
- **出擊準備**（章節設定）：選擇出擊成員、輸送隊整備、商店買賣（軍資金由劇情取得）。
- **霧戰**（章節設定）：只看得到我方視野內的敵人；盜賊、天馬騎士視野較廣。
- SRW 要素（劇本可開關）：**氣力**（戰鬥 +1、命中 +1、擊破 +3；傷害 × 攻方氣力 / 守方氣力；部分必殺技需要氣力）、**精神指令**（SP 每章回滿）。

## 轉職與改造
- **轉職**：職業可設定轉職路線（等級條件、轉職道具、能力加成、新技能/武器）。示範劇本中 Lv5 以上在戰鬥中使用「騎士勳章」即可轉職（領主→晨星領主、騎士→聖騎士…）；也可用劇本指令「轉職」。
- **改造**（劇本可開關）：出擊準備畫面的「改造」分頁，花軍資金強化武器（每級威力 +1、命中 +3）與 HP/守備/魔防。
- **動作影格**：像素精靈的每個影格可標記為待機/攻擊/受擊，戰鬥演出衝向對方時換攻擊影格、被打中時換受擊影格。

## 戰鬥演出與音效
- 攻擊時會切到戰鬥演出畫面（我方在右、敵方在左），點擊或按鍵可快轉；「⚙ 設定」可改為「只播必殺技」或關閉，並調整動畫速度、音效/BGM 音量。
- 演出是**資料驅動的時間軸**：編輯器「🎬 戰鬥演出」分頁可新增/排列步驟（移動、命中結算、粒子、飛行道具、閃光、震動、背景染色、大字、SRW 頭像切入、音效），即時預覽；武器頁指定要用哪個演出。
- 「🏞 戰鬥背景」依地形調整天空/地面顏色、景物或上傳背景圖。
- 「🔊 音效/BGM」可試聽與編輯合成音效（波形、頻率、滑音、時間）、用音符語法寫 BGM（`C5 E5:0.5 R:1`）、上傳自己的音檔；用系統音效 ID（hit、crit、levelup…）覆寫即可替換遊戲音效，章節可指定我方/敵方 BGM。
- 地圖可用「－ ⤢ ＋」或 Ctrl+滾輪縮放；手機上長按單位可查看其範圍。

## 存檔
- 3 個本機欄位（localStorage），可在戰鬥中「中斷存檔」；存檔包含名冊、旗標、軍資金、輸送隊與支援關係。
- 每個欄位可「⬇ 下載為存檔檔案」；標題畫面「匯入存檔檔案」讀回 → 存檔真正保存在玩家電腦。

## 編輯器工作流程
1. 開 `editor.html`（預設載入示範劇本；內容自動暫存在瀏覽器）。
2. 編輯各分頁 → **▶ 試玩**（新分頁直接進入目前章節）。
3. **💾 存為遊戲劇本** → 遊戲標題選「編輯器中的劇本」。
4. **⬇ 匯出 JSON** 備份 / 分享；遊戲標題「從檔案載入劇本…」可直接讀 JSON。

## AI 協助繪圖 / 寫劇本（不需 API Key）
參考 HOMEGUARD 專案的做法：精靈圖存成 **ASCII 字元網格 + palette**、地圖存成**字元列**，聊天 AI 能直接讀懂並修改。
1. 編輯器 **🤖 AI 協作包** → 勾選範圍（精靈圖 / 地圖章節 / 劇情 / 數值）→ 寫委託任務 → 下載 `.md` 或複製。
2. 貼給 ChatGPT / Claude / Gemini（有參考圖就一起上傳）。
3. 把 AI 的回覆整段貼到 **⬆ 匯入 AI 回傳**：自動抓出 JSON、預覽新增/修改了哪些 id、檢查錯誤，確認後合併。

精靈圖的 palette 可用 `"team"` / `"teamDark"` / `"teamLight"`，遊戲會依我方（藍）/敵方（紅）/友軍（綠）自動換色，一張圖三方共用。
也可在精靈圖分頁「📥 匯入 PNG/JPG」（自動縮放、去背、減色轉成 ASCII），或「🖼 匯入圖片精靈」使用 RPG Maker 規格行走圖。

## 素材
- `assets/characters.png`：RPG Maker 規格行走圖（開源素材），示範劇本角色使用；編輯器「精靈圖」分頁可一鍵加入。
- `assets/icons.png`：kyrise（kyrise.itch.io）圖示包，武器/道具圖示；編輯器中點「選擇…」挑圖示。

## 手機遊玩
- 支援手機/平板瀏覽器：點選操作、長按看範圍、拖曳捲動地圖；移動/選目標/再移動時右下角有「✕ 取消」按鈕。
- 下方資訊列預設精簡，點一下展開完整能力與持有物；地圖縮放在「☰ 選單」中。
- 可「加入主畫面」以全螢幕開啟（PWA manifest）。編輯器建議在電腦或平板上使用。

## 放到 GitHub Pages
純靜態網站，不需建置：Repo → Settings → Pages → Source 選「Deploy from a branch」→ 選分支、資料夾選 `/ (root)` → 儲存。
網址為 `https://<帳號>.github.io/<repo>/`，根目錄 `index.html` 會自動轉到 `srpg/`。（私人 repo 需付費方案才能開 Pages。）

## 本機伺服器（選用）
直接雙擊即可運作。若想用 http 開啟：`python -m http.server 8080` → `http://localhost:8080/srpg/`。
